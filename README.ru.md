# Galaxy Editor

Редактор карт для [Total Annihilation](https://en.wikipedia.org/wiki/Total_Annihilation), для macOS, Windows и Linux.

Рисуйте плитки, размещайте деревья и металл, устанавливайте стартовые позиции игроков и формируйте высоту местности. Карты открываются и сохраняются как файлы `.ufo`, которые игра может загрузить.

В Linux вы можете использовать пакет `.deb` или распаковать архив `.tar.gz`. Каждая загрузка включает `GE-Favorites-RandomMapGeneratorTiles.hpi` рядом с приложением. Кисть плиток читает этот набор плиток, поэтому держите файл рядом с `GalaxyEditor.app`, `GalaxyEditor.exe` или Linux `GalaxyEditor`. `GreenWorld.hpi` включен таким же образом. При первом запуске Galaxy Editor сначала спрашивает язык, а затем где установлен Total Annihilation. Каждый выпуск перечислен на [странице выпусков](https://github.com/MattA9K/Total-Annihilation-Galaxy-Editor/releases).

### Установка Linux

**Вариант 1: Установка через пакет .deb (Debian/Ubuntu/Mint)**

The `.deb` is not on the v1.1.2 release, so there is no download URL for it yet. The package file name is `galaxy-editor_<version>_amd64.deb`. For version 1.1.2 that name is `galaxy-editor_1.1.2_amd64.deb`. When a later release includes the file, install the downloaded package with:

```bash
sudo apt install ./galaxy-editor_1.1.2_amd64.deb
```

Until then, use the `.tar.gz` below. That archive is what works today.

**Вариант 2: Использование портативного архива**

```bash
wget https://github.com/MattA9K/Total-Annihilation-Galaxy-Editor/releases/download/v1.1.2/GalaxyEditor-1.1.2-linux-x64.tar.gz
tar -xzf GalaxyEditor-1.1.2-linux-x64.tar.gz
cd GalaxyEditor-1.1.2-linux-x64
./GalaxyEditor
```

## Что вы можете делать

**Плитки и особенности.** Ищите наборы плиток, которые поставляются с игрой, щёлкните по разделу и проштампуйте его на карте. Деревья, камни, металлические пятна и отверстия используют свою графику из игры. Стартовые булавки отмечают, где каждый игрок начинает.

**Местность.** Включите карту высот, затем поднимите, опустите или установите высоту выделения. Скопируйте местность и высоту вместе или скопируйте только высоту и оставьте плитки на месте. Blend Textures размывает изображения там, где выделение встречается с плитками вокруг него.

**Сама карта.** Настройки карты содержат значения, которые игра читает с карты: ветер, приливы, солнечная сила, гравитация, уровень моря, металл, профиль AI и специальные правила. Генерация карты строит новый ландшафт из набора плиток. Миникарта располагается над углом обзора, а отмена охватывает редактирование плиток, особенностей и высоты.

**3D вид.** Кнопка 3D вида на панели инструментов (меню Вид, Ctrl+3) показывает карту как местность с картой высот, поднимающей землю. Полупрозрачная плоскость отмечает уровень моря из настроек карты, а параметры редактора устанавливают её цвет и непрозрачность. 3D вид предназначен для осмотра, поэтому редактируйте в плоском виде и переключайтесь туда-сюда, как вам нравится.

## Сборка

Вам нужны CMake 3.24 или новее, компилятор C++20, zlib и OpenGL. Первая конфигурация загружает [GLFW](https://www.glfw.org/) 3.4 и [Dear ImGui](https://github.com/ocornut/imgui) 1.91.8, поэтому этот шаг требует сетевого подключения.

macOS собирает `build/GalaxyEditor.app`. Откройте его из Finder или запустите `open build/GalaxyEditor.app`:

```bash
cmake --preset default
cmake --build build
open build/GalaxyEditor.app
```

Linux:

```bash
cmake --preset default
cmake --build build
./build/galaxy-editor
```

Чтобы собрать Windows `.exe` на Mac или Linux машине, установите MinGW-w64 (`brew install mingw-w64` или `apt install g++-mingw-w64-x86-64-posix`), затем:

```bash
cmake --preset windows
cmake --build --preset windows
```

Это записывает `build-windows/GalaxyEditor.exe`. Это один файл с встроенной C++ runtime, и ему нужны только DLL, которые поставляются с Windows. Первая конфигурация также загружает zlib. Поместите свои собственные архивы наборов плиток рядом с `.exe`.

В самом Windows выберите генератор, который понимает ваш компилятор:

```bat
cmake -S . -B build
cmake --build build --config Release
```

zlib должен быть виден для CMake. В Debian и Ubuntu это пакет `zlib1g-dev`. В Fedora это `zlib-devel`. Диалоги открытия и сохранения Linux используют Zenity.

Тесты формата собираются с редактором:

```bash
cmake --build build --target galaxy_tests
./build/galaxy_tests
```

## Наборы плиток

Galaxy Editor загружает игровые архивы из вашей папки установки Total Annihilation. При самом первом запуске, до экрана загрузки, он спрашивает язык, а затем эту папку. Выберите Отмена, чтобы запустить без неё. Редактор всё ещё работает, но вкладки Наборы плиток и Особенности остаются пустыми, и он не спрашивает снова при следующем запуске.

Измените папку в любое время в Параметрах, под Total Annihilation. Выбор папки сразу перезагружает архивы, а Очистить забывает папку, поэтому следующий запуск снова спрашивает о ней, как при первом запуске. Папка и выбранный язык сохраняются в `settings.json` для каждого пользователя. Язык потом меняется в Параметрах, в разделе Язык, и окно переключается сразу.

Galaxy Editor читает файлы `.hpi`, `.ccx`, `.gp3` и `.gpf` непосредственно в этой папке, а затем в папке, содержащей исполняемый файл `GalaxyEditor`. В macOS это папка, содержащая `GalaxyEditor.app`, поэтому папка с именем Galaxy Editor с приложением и вашими собственными файлами `.hpi` рядом работает, как размещён Photoshop. Поместите свои собственные архивы наборов плиток рядом с исполняемым файлом (или `.app`). Если файл там имеет то же имя, что и один в папке Total Annihilation, например `worlds.hpi` или `totala1.hpi`, он пропускается, поэтому ничто не загружается дважды. Мировой архив, такой как `worlds.hpi`, заполняет вкладку Наборы плиток. `totala1.hpi`, `rev31.gp3` или `ccdata.ccx` предоставляют список особенностей и изображения особенностей.

Эти архивы являются игровыми данными. Они не являются частью этого репозитория.

Открыть карту читает `.ufo`, `.hpi` и `.tnt`. Сохранить записывает `.ufo`.

## Избранное

Вкладка Избранное, между Наборы плиток и Особенности, содержит плитки, которые вы сохраняете сами. В режиме Выбрать плитки выберите некоторые плитки и щёлкните правой кнопкой мыши. Меню предлагает Вырезать, Копировать, Копировать высоты, Изменить высоту, Смешать и Добавить в избранное. Во вкладке Наборы плиток наведение на изображение показывает кнопку звезды в его углу, которая добавляет эту плитку. Во вкладке Избранное тот же угол содержит кнопку корзины, которая удаляет плитку после подтверждения.

Добавить в избранное спрашивает о трёх вещах: архив избранного, категория и подкатегория. Введите новые имена или выберите существующие. Имена работают так, как они работают в собственных наборах плиток игры: в `Acid_New_1.hpi` категория - Acid_New_1, а Rivers и Sm Lakes - её подкатегории. Создать архив избранного спрашивает имя, такое как FirstOne, и записывает `GE-Favorites-FirstOne.hpi` рядом с исполняемым файлом `GalaxyEditor` (рядом с `.app` на macOS).

Только архивы с именем `GE-Favorites-<имя>.hpi` появляются на вкладке Избранное, и они держатся подальше от вкладки Наборы плиток. Внутри плитка - `sections/<категория>/<подкатегория>/<плитка>.sct`, поэтому архив - это обычный набор плиток, которым вы можете поделиться, скопировав файл в чью-то другую папку. Сохранённая плитка - это полный прямоугольник. Когда выделение имеет пробелы, плитки между выбранными также сохраняются, потому что файл раздела не имеет места для дырок. Плитка может быть максимум 512 плиток с каждой стороны.

## HPI редактор

Кнопка HPI редактор на правом конце панели инструментов (меню Файл, HPI редактор) открывает браузер файлов для архивов: `.hpi`, `.ufo`, `.ccx`, `.gp3` и `.gpf`. Откройте один кнопкой Открыть или начните пустой архив с Новый. Когда карта, которую вы открыли, сама является архивом, пустое окно предлагает его одним щелчком.

Окно следует макету окна Finder. Дерево папок спускается слева, содержимое заполняет середину как список или как значки (две кнопки вверху справа), а строка пути и количество элементов проходят по низу. Щёлкните по папке в дереве или сегменту строки пути, чтобы перейти туда, дважды щёлкните по папке, чтобы открыть её, и используйте Назад и Вперёд, чтобы отследить свои шаги. Выберите щелчком, Command-щелчком или Ctrl-щелчком, чтобы добавить один, Shift-щелчком для диапазона или Ctrl+A. Поле поиска находит файлы и папки по имени под папкой, которую вы просматриваете, и двойной щелчок по результату показывает, где он находится.

- **Экспорт** копирует выбранные файлы и папки в папку, которую вы выбираете. Папка сохраняет своё имя и всё в ней. Без ничего выбранного, Экспорт берёт папку, которую вы просматриваете, и наверху архива создаётся папка, названная по имени архива, чтобы его содержимое не распространялось. Если файл уже там, вас спрашивают перед тем, как его заменить. Имена, которые могут достичь за пределы папки, которую вы выбрали, пропускаются, а символы, которые компьютер не разрешает в именах файлов, заменяются подчёркиванием.
- **Импорт** добавляет файлы или целые папки со всем в них в папку, которую вы просматриваете. Вы также можете перетащить файлы и папки с рабочего стола на окно. Импорт спрашивает перед заменой файла с таким же именем. Имена файлов в архиве совпадают без учёта регистра, как они это делают в игре.
- **Переместить** перетаскиванием элементов из одной папки в другую: на папку в списке или виде значков, папку в дереве или сегмент строки пути. Перетаскивание папки в саму себя отклоняется, а папка, которая уже существует в месте назначения, объединяется в неё.
- **Переименовать** с F2 или меню правой кнопки, **Новая папка** с кнопки панели инструментов или Ctrl+Shift+N, и **Удалить** клавишей Delete. Каждое изменение можно отменить и повторить.

Ничего не касается архива на диске, пока вы не нажмёте Сохранить. Сохранить и Сохранить как записывают новый архив и заменяют старый файл за один шаг, поэтому сбой оставляет оригинал в покое. Архив не может хранить пустую папку или вообще не иметь файлов, поэтому пустые папки не переживают сохранение, и редактор не сохранит архив без ничего в нём. Закрытие окна, открытие другого архива или выход сначала спрашивает о несохранённых изменениях.

## Сочетания клавиш

В macOS Command занимает место Ctrl.

| Действие | Сочетание |
| --- | --- |
| Новая карта | Ctrl+N |
| Открыть карту | Ctrl+O |
| Сохранить | Ctrl+S |
| Сохранить как | Ctrl+Shift+S |
| Выйти | Ctrl+Q |
| Отменить | Ctrl+Z |
| Повторить | Ctrl+Shift+Z |
| Вырезать | Ctrl+X |
| Копировать местность + карту высот | Ctrl+C |
| Копировать карту высот | Ctrl+Shift+C |
| Вставить | Ctrl+V |
| Параметры редактора | Ctrl+, |
| 3D вид включён или выключен | Ctrl+3 |

В окне HPI редактора они работают, когда оно имеет клавиатуру вместо сочетаний карты: Ctrl+O открывает архив, Ctrl+N начинает новый, Ctrl+S и Ctrl+Shift+S сохраняют, Ctrl+Z и Ctrl+Shift+Z отменяют и повторяют, Ctrl+A выбирает всё, Ctrl+I импортирует, Ctrl+Shift+N создаёт папку, Ctrl+[ и Ctrl+] идут назад и вперёд, Ctrl+Up идёт к обёртывающей папке, Ctrl+Down или Return открывает папку, F2 переименовывает, Delete или Ctrl+Backspace удаляет выделение, а один Backspace поднимается на одну папку.

Клавиши со стрелками сдвигают штамп или вставку с плитки под курсором. Esc отменяет вставку, выходит из режима Удалить или очищает выделение.

В 3D виде перетащите, чтобы вращаться по орбите, правой перетащите или Shift-перетащите для панорамирования и прокрутите для увеличения. W A S D (или клавиши со стрелками) двигаются по земле, Shift двигается быстрее, Q и E поворачивают, а Home начинает заново.

Параметры редактора запоминаются в следующий раз, когда вы открываете редактор. Размер предварительного просмотра, интервал карты высот, размер текста боковой панели и автосохранение - всё живёт там. Автосохранение записывает резервную копию рядом с картой по таймеру и оставляет файл из Сохранить в покое.
