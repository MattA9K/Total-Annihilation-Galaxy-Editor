# Galaxy Editor

Рэдактар мапаў для [Total Annihilation](https://en.wikipedia.org/wiki/Total_Annihilation), для macOS, Windows і Linux.

Малюйце пліткі, размяшчайце дрэвы і метал, усталёўвайце пачатковыя пазіцыі гульцоў і фармуйце вышыню мясцовасці. Мапы адкрываюцца і захоўваюцца як файлы `.ufo`, якія гульня можа загрузіць.

У macOS адкрыйце вобраз дыска і перацягніце папку Galaxy Editor у папку Праграмы. У Windows распакуйце архіў і запусціце `GalaxyEditor.exe`. У Linux вы можаце выкарыстоўваць пакет `.deb` або распакаваць архіў `.tar.gz`. Кожная спампоўка ўключае `GE-Favorites-RandomMapGeneratorTiles.hpi` побач з праграмай. Пэндзаль плітак чытае гэты набор плітак, таму трымайце файл побач з `GalaxyEditor.app`, `GalaxyEditor.exe` або Linux `GalaxyEditor`. `GreenWorld.hpi` уключаны такім жа чынам. Пры першым запуску Galaxy Editor спачатку пытае мову, а потым дзе ўсталяваны Total Annihilation. Кожны выпуск пералічаны на [старонцы выпускаў](https://github.com/MattA9K/Total-Annihilation-Galaxy-Editor/releases).

### Усталёўка Linux

**Варыянт 1: Усталёўка праз пакет .deb (Debian/Ubuntu/Mint)**

The `.deb` is not on the v1.1.2 release, so there is no download URL for it yet. The package file name is `galaxy-editor_<version>_amd64.deb`. For version 1.1.2 that name is `galaxy-editor_1.1.2_amd64.deb`. When a later release includes the file, install the downloaded package with:

```bash
sudo apt install ./galaxy-editor_1.1.2_amd64.deb
```

Until then, use the `.tar.gz` below. That archive is what works today.

**Варыянт 2: Выкарыстанне партатыўнага архіва**

```bash
wget https://github.com/MattA9K/Total-Annihilation-Galaxy-Editor/releases/download/v1.1.2/GalaxyEditor-1.1.2-linux-x64.tar.gz
tar -xzf GalaxyEditor-1.1.2-linux-x64.tar.gz
cd GalaxyEditor-1.1.2-linux-x64
./GalaxyEditor
```

## Што вы можаце рабіць

**Пліткі і асаблівасці.** Шукайце наборы плітак, якія пастаўляюцца з гульнёй, пстрыкніце па раздзеле і праштампуйце яго на мапу. Дрэвы, камяні, металічныя плямы і адтуліны выкарыстоўваюць сваю графіку з гульні. Пачатковыя шпількі пазначаюць, дзе кожны гулец пачынае.

**Мясцовасць.** Уключыце карту вышынь, затым падніміце, апусціце або ўсталюйце вышыню вылучэння. Скапіюйце мясцовасць і вышыню разам або скапіюйце толькі вышыню і пакіньце пліткі на месцы. Blend Textures размывае выявы там, дзе вылучэнне сустракаецца з плітка вакол яго.

**Сама мапа.** Налады мапы ўтрымліваюць значэнні, якія гульня чытае з мапы: вецер, прылівы, сонечная сіла, гравітацыя, узровень мора, метал, профіль AI і спецыяльныя правілы. Генерацыя мапы будуе новы ландшафт з набору плітак. Мінімапа размяшчаецца над вуглом выгляду, а адмена ахоплівае рэдагаванні плітак, асаблівасцей і вышыні.

**3D выгляд.** Кнопка 3D выгляду на панэлі інструментаў (меню Выгляд, Ctrl+3) паказвае мапу як мясцовасць з картай вышынь, якая падымае зямлю. Паўпразрыстая плоскасць пазначае ўзровень мора з налад мапы, а параметры рэдактара ўсталёўваюць яе колер і непразрыстасць. 3D выгляд прызначаны для агляду, таму рэдагуйце ў плоскім выглядзе і пераключайцеся туды-сюды, як вам падабаецца.

## Зборка

Вам патрэбны CMake 3.24 або навейшы, кампілятар C++20, zlib і OpenGL. Першая канфігурацыя загружае [GLFW](https://www.glfw.org/) 3.4 і [Dear ImGui](https://github.com/ocornut/imgui) 1.91.8, таму гэты крок патрабуе сеткавага злучэння.

macOS будуе `build/GalaxyEditor.app`. Адкрыйце яго з Finder або запусціце `open build/GalaxyEditor.app`:

```bash
cmake --preset default
cmake --build build
open build/GalaxyEditor.app
```

Linux:

```bash
cmake --preset default
cmake --build build
./build/galaxy-editor
```

Каб пабудаваць Windows `.exe` на Mac або Linux машыне, усталюйце MinGW-w64 (`brew install mingw-w64` або `apt install g++-mingw-w64-x86-64-posix`), затым:

```bash
cmake --preset windows
cmake --build --preset windows
```

Гэта піша `build-windows/GalaxyEditor.exe`. Гэта адзін файл з убудаваным C++ runtime, і яму патрэбны толькі DLL, якія пастаўляюцца з Windows. Першая канфігурацыя таксама загружае zlib. Размясціце свае ўласныя архівы набораў плітак побач з `.exe`.

У самім Windows выберыце генератар, які разумее ваш кампілятар:

```bat
cmake -S . -B build
cmake --build build --config Release
```

zlib павінен быць бачным для CMake. У Debian і Ubuntu гэта пакет `zlib1g-dev`. У Fedora гэта `zlib-devel`. Дыялогі адкрыцця і захавання Linux выкарыстоўваюць Zenity.

Тэсты фармату будуюцца з рэдактарам:

```bash
cmake --build build --target galaxy_tests
./build/galaxy_tests
```

## Наборы плітак

Galaxy Editor загружае гульнявыя архівы з вашай папкі ўсталёўкі Total Annihilation. Пры самым першым запуску, да экрана загрузкі, ён пытае мову, а потым гэту папку. Выберыце Адмяніць, каб запусціць без яе. Рэдактар усё яшчэ працуе, але ўкладкі Наборы плітак і Асаблівасці застаюцца пустымі, і ён не пытае зноў пры наступным запуску.

Змяніце папку ў любы час у Параметрах, пад Total Annihilation. Выбар папкі адразу перазагружае архівы, а Ачысціць забывае папку, таму наступны запуск зноў пытае пра яе, як пры першым запуску. Папка і абраная мова захоўваюцца ў `settings.json` для кожнага карыстальніка. Мову потым можна змяніць у Параметрах, у раздзеле Мова, і акно пераключыцца адразу.

Galaxy Editor чытае файлы `.hpi`, `.ccx`, `.gp3` і `.gpf` непасрэдна ў гэтай папцы, а затым у папцы, якая ўтрымлівае выконваемы файл `GalaxyEditor`. У macOS гэта папка, якая ўтрымлівае `GalaxyEditor.app`, таму папка з назвай Galaxy Editor з праграмай і вашымі ўласнымі файламі `.hpi` побач працуе, як размешчаны Photoshop. Размясціце свае ўласныя архівы набораў плітак побач з выконваемым файлам (або `.app`). Калі файл там мае такое ж імя, як адзін у папцы Total Annihilation, напрыклад `worlds.hpi` або `totala1.hpi`, ён прапускаецца, таму нічога не загружаецца двойчы. Сусветны архіў, такі як `worlds.hpi`, запаўняе ўкладку Наборы плітак. `totala1.hpi`, `rev31.gp3` або `ccdata.ccx` даставяюць спіс асаблівасцей і малюнкі асаблівасцей.

Гэтыя архівы з'яўляюцца гульнявымі данымі. Яны не з'яўляюцца часткай гэтага рэпазітарыя.

Адкрыць мапу чытае `.ufo`, `.hpi` і `.tnt`. Захаваць піша `.ufo`.

## Выбранае

Укладка Выбранае, паміж Наборы плітак і Асаблівасці, утрымлівае пліткі, якія вы захоўваеце самі. У рэжыме Выбраць пліткі выберыце некаторыя пліткі і пстрыкніце правай кнопкай мышы. Меню прапануе Выразаць, Капіяваць, Капіяваць вышыні, Змяніць вышыню, Змяшаць і Дадаць у выбранае. На ўкладцы Наборы плітак навядзенне на малюнак паказвае кнопку зоркі ў яго куце, якая дадае гэтую пліткі. На ўкладцы Выбранае той жа кут утрымлівае кнопку сметніцы, якая выдаляе пліткі пасля пацверджання.

Дадаць у выбранае пытае пра тры рэчы: архіў выбранага, катэгорыю і падкатэгорыю. Увядзіце новыя назвы або выберыце існуючыя. Назвы працуюць так, як яны працуюць у ўласных наборах плітак гульні: у `Acid_New_1.hpi` катэгорыя - Acid_New_1, а Rivers і Sm Lakes - яе падкатэгорыі. Стварыць архіў выбранага пытае імя, такое як FirstOne, і піша `GE-Favorites-FirstOne.hpi` побач з выконваемым файлам `GalaxyEditor` (побач з `.app` на macOS).

Толькі архівы з імем `GE-Favorites-<імя>.hpi` з'яўляюцца на ўкладцы Выбранае, і яны трымаюцца далёка ад укладкі Наборы плітак. Унутры пліткі - `sections/<катэгорыя>/<падкатэгорыя>/<пліткі>.sct`, таму архіў - гэта звычайны набор плітак, якім вы можаце падзяліцца, скапіраваўшы файл у папку каго-небудзь іншага. Захаваная пліткі - гэта поўны прамавугольнік. Калі вылучэнне мае прабелы, пліткі паміж выбранымі таксама захоўваюцца, таму што файл раздзела не мае месца для дзірак. Пліткі можа быць максімум 512 плітак з кожнага боку.

## HPI рэдактар

Кнопка HPI рэдактар на правым канцы панэлі інструментаў (меню Файл, HPI рэдактар) адкрывае браўзер файлаў для архіваў: `.hpi`, `.ufo`, `.ccx`, `.gp3` і `.gpf`. Адкрыйце адзін кнопкай Адкрыць або пачніце пусты архіў з Новы. Калі мапа, якую вы адкрылі, сама з'яўляецца архівам, пустое акно прапануе яе адным клікам.

Акно сачыць за макетам акна Finder. Дрэва папак спускаецца злева, змесціво запаўняе сярэдзіну як спіс або як значкі (дзве кнопкі ўверсе справа), а радок шляху і колькасць элементаў праходзяць па нізе. Пстрыкніце па папцы ў дрэве або сегменце радка шляху, каб перайсці туды, двойчы пстрыкніце па папцы, каб адкрыць яе, і выкарыстоўвайце Назад і Наперад, каб адсачыць свае крокі. Выберыце клікам, Command-кліком або Ctrl-клікам, каб дадаць адзін, Shift-клікам для дыяпазону або Ctrl+A. Поле пошуку знаходзіць файлы і папкі па назве пад папкай, якую вы праглядаеце, і двойчы пстрыкніце па выніку, каб паказаць, дзе ён знаходзіцца.

- **Экспарт** капіюе выбраныя файлы і папкі ў папку, якую вы выбіраеце. Папка захоўвае сваё імя і ўсё ў ёй. Без нічога выбранага, Экспарт бярэ папку, якую вы праглядаеце, і наверсе архіва ствараецца папка, названая па назве архіва, каб яго змесціва не распаўсюджвалася. Калі файл ужо там, вас пытаюць перад тым, як яго замяніць. Назвы, якія могуць дасягнуць за межы папкі, якую вы выбралі, прапускаюцца, а сімвалы, якія кампутар не дазваляе ў назвах файлаў, замяняюцца падкрэсліваннем.
- **Імпарт** дадае файлы або цэлыя папкі з усім у іх у папку, якую вы праглядаеце. Вы таксама можаце перацягнуць файлы і папкі з працоўнага стала на акно. Імпарт пытае перад заменай файла з такім жа імем. Назвы файлаў у архіве супадаюць без улікі рэгістра, як яны гэта робяць у гульні.
- **Перамясціць** перацягваннем элементаў з адной папкі ў іншую: на папку ў спісе або выглядзе значкоў, папку ў дрэве або сегмент радка шляху. Перацягванне папкі ў саму сябе адхіляецца, а папка, якая ўжо існуе ў месцы прызначэння, аб'ядноўваецца ў яе.
- **Перайменаваць** з F2 або меню правай кнопкі, **Новая папка** з кнопкі панэлі інструментаў або Ctrl+Shift+N, і **Выдаліць** клавішай Delete. Кожнае змяненне можна адмяніць і паўтарыць.

Нічога не датыкаецца архіва на дыску, пакуль вы не націснеце Захаваць. Захаваць і Захаваць як пішуць новы архіў і замяняюць стары файл за адзін крок, таму збой пакідае арыгінал у спакоі. Архіў не можа захоўваць пустую папку або наогул не мець файлаў, таму пустыя папкі не перажываюць захаванне, і рэдактар не захавае архіў без нічога ў ім. Закрыццё акна, адкрыццё іншага архіва або выхад спачатку пытае пра незахаваныя змены.

## Спалучэнні клавіш

У macOS Command займае месца Ctrl.

| Дзеянне | Спалучэнне |
| --- | --- |
| Новая мапа | Ctrl+N |
| Адкрыць мапу | Ctrl+O |
| Захаваць | Ctrl+S |
| Захаваць як | Ctrl+Shift+S |
| Выйсці | Ctrl+Q |
| Адмяніць | Ctrl+Z |
| Паўтарыць | Ctrl+Shift+Z |
| Выразаць | Ctrl+X |
| Капіяваць мясцовасць + карту вышынь | Ctrl+C |
| Капіяваць карту вышынь | Ctrl+Shift+C |
| Уставіць | Ctrl+V |
| Параметры рэдактара | Ctrl+, |
| 3D выгляд уключаны або выключаны | Ctrl+3 |

У акне HPI рэдактара яны працуюць, калі яно мае клавіятуру замест спалучэнняў мапы: Ctrl+O адкрывае архіў, Ctrl+N пачынае новы, Ctrl+S і Ctrl+Shift+S захоўваюць, Ctrl+Z і Ctrl+Shift+Z адмяняюць і паўтараюць, Ctrl+A выбірае ўсё, Ctrl+I імпартуе, Ctrl+Shift+N стварае папку, Ctrl+[ і Ctrl+] ідуць назад і наперад, Ctrl+Up ідзе да абгортвальнай папкі, Ctrl+Down або Return адкрывае папку, F2 перайменоўвае, Delete або Ctrl+Backspace выдаляе вылучэнне, а адзін Backspace падымаецца на адну папку.

Клавішы са стрэлкамі зрушаюць штамп або ўстаўку з пліткі пад курсорам. Esc адмяняе ўстаўку, выходзіць з рэжыму Выдаліць або ачышчае вылучэнне.

У 3D выглядзе перацягніце, каб арбітаваць, правай перацягніце або Shift-перацягніце для панарамавання і пракруціце для павелічэння. W A S D (або клавішы са стрэлкамі) рухаюцца па зямлі, Shift рухаецца хутчэй, Q і E круцяць, а Home пачынае зноў.

Параметры рэдактара запамінаюцца наступным разам, калі вы адкрываеце рэдактар. Памер папярэдняга прагляду, інтэрвал карты вышынь, памер тэксту бакавой панэлі і аўтазахаванне - усё жыве там. Аўтазахаванне піша рэзервовую копію побач з мапай па таймеру і пакідае файл з Захаваць у спакоі.
